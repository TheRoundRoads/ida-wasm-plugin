## WebAssembly decompilation inside IDA

This initial public preview provides C-like pseudocode for WebAssembly in
IDA Pro 9.0+, with navigation and cross-references in the original Wasm database.

### Highlights

- Scalar Wasm decompilation with expression cleanup, structured loops and switches,
  and conservative stack recovery.
- Tab toggling between disassembly and pseudocode.
- Enter/double-click call following in the same viewer, with back/forward history.
- Go to address (`G`), symbol cross-references (`X`), renaming (`N`), and refresh (`R`).
- Persistent, typed global identities with real IDA read/write cross-references.
- Function/module export and a standalone CLI with JSON source maps and diagnostics.
- A portable installation ZIP with only the entry-point file at the plugins-directory
  level; all modules, documentation, and license files stay under `wasm_decompiler/`.

### Installation

1. Download **`ida-wasm-decompiler-0.3.0.zip`** from this release's assets.
2. Close IDA and extract the ZIP contents into IDA's **user plugins directory**.
   Keep `ida_wasm_decompiler.py` beside the `wasm_decompiler/` directory.
3. Restart IDA, open a `.wasm` file with the built-in loader, and press **Tab**
   while the cursor is inside a function.

Use the installation asset above; GitHub's automatically generated source archives
contain the repository rather than the ready-to-install plugin layout.
An accompanying `.sha256` file is provided for integrity verification.

[Full installation and usage guide](https://github.com/TheRoundRoads/ida-wasm-plugin/blob/v0.3.0/README.md#installation)

### Compatibility and limitations

- Requires IDA Pro 9.0+ and IDAPython with Python 3.9+.
- Runtime-tested on Linux with IDA 9.0. Selected public APIs were checked against
  official 9.2–9.4 SDKs; those checks do not replace runtime validation there.
- No additional Python packages, Ghidra installation, or Hex-Rays decompiler are
  required for plugin use.
- This is a custom pseudocode viewer. It does **not** enable
  `ida_hexrays.decompile()` for Wasm or return native Hex-Rays `cfunc_t` objects.
- Output is inspection pseudocode, not guaranteed recompilable C. Complex exits
  can retain labels; large functions can take longer to analyze.
- Modern extensions including SIMD, GC, atomics, exceptions, memory64, and
  multi-value signatures are not supported in this release.

### Validation

- **228 automated tests passed**, including **866 execution comparisons** against WABT.
- IDA GUI/headless checks covered navigation, the `run → _f1387` regression,
  global xrefs, renaming, patch re-indexing, export, and saved-database reopening.

[Validation details](https://github.com/TheRoundRoads/ida-wasm-plugin/blob/v0.3.0/docs/VALIDATION.md)
